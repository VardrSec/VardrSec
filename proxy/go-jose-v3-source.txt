bounds and rejection of private embedded header keys. Adapt the general JWS
unprotected-header assignment without importing v4's algorithm-list API change.

explicit private JWK parsing remain supported; oversized/malformed keys and
private keys embedded in public headers are refused. This affects JWK parsing,
not a blanket limit on PEM/TLS certificate key sizes.

source, patched source, patch, license, module identity, Go module replacement
and build metadata accompany this notice. The local replacement is an actual
source backport, not an upstream fixed v3 version; scanners must retain that
