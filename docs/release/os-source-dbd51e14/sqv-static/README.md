# Exact sqv static dependency source supplement

This supplement applies to the reviewed Debian `sqv 1.3.0-3+b2`, not automatically to later image versions. Its authenticated package metadata declares 65 `Static-Built-Using` source/version pairs, including six explicit `Built-Using` pairs. All 65 exact source identities were captured: 196 descriptors, original source archives and Debian patchsets, totalling 95,025,162 bytes. No source was compiled or executed for this acquisition. An additional 267 license/copyright notices were retained for review.

`inventory.json` lists the source identities; `capture.json` records exact source URLs, sizes and hashes. `sqv-signed-index-stanza.txt` preserves the binary package metadata. Source indexes and the binary Packages index were verified against retained Debian trixie/security InRelease signatures using an independently trusted archive keyring. Every source file was matched to its authenticated source-index record, and the complete static dependency set was checked. `verification.json` records the bounded result.

The retained `sqv-static-source-closure.tar` is 117,964,800 bytes, SHA256 `8e608e2ef460b58ed046b4fac4c40d47e7c46e3b5810b98f57ab3da3754f0999`. It includes the authenticated metadata, complete source inputs, retained notices and an offline `verify_capture.py` verifier. After extracting into a new dedicated directory, run that verifier with an existing trusted Debian archive keyring; it needs the existing sqv utility and does not install software or execute the source. Do not run Python with optimization enabled, which disables this verifier's assertion checks.

This closes the identified exact-source retention gap, not all recursive build-tool dependencies, source-to-binary reproduction, LGPL relinking, license compatibility or recipient delivery. A stable recipient-facing location for the complete retained bundle and final image reconciliation remain release requirements; this documentation is neither a published release nor a formal written source offer.
